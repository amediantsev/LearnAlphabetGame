# Режим «Знайди» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third mode «Знайди»: picture + auto-spoken «а… автобус» + four letter tiles; wrong tiles turn red and lock, the right one turns green with ✓ and reveals the word; ▶ moves on.

**Architecture:** All quiz rules live in pure Kotlin under `app/src/main/java/app/learnalphabet/quiz/` (question state, question order, auto-speak gate) and are unit-tested on the JVM. `CardViewModel` gains a third mode and owns one quiz deck, one current question and one auto-speak gate. Compose renders the quiz body in a new `QuizContent.kt`; `CardScreen` switches between card body and quiz body.

**Tech Stack:** unchanged — Kotlin 2.0.20, AGP 8.5.2, Compose BOM 2024.09.02, JUnit 4. JDK 17 at `/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home`.

**Spec:** `docs/superpowers/specs/2026-10-30-quiz-mode-design.md` (extends `docs/superpowers/specs/2026-10-29-learn-alphabet-design.md`). Approved mockup (not in git): `.superpowers/brainstorm/65269-1793371405/content/quiz-layout.html`, variant A.

## Global Constraints

- Every gradle command: `export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home` first.
- 4 options in a 2×2 grid; tiles show the **uppercase** letter only.
- Spoken prompt is exactly the card's: `speaker.speak(card)` (letter name, pause, word). No other sounds anywhere.
- Auto-speak once per new question; never on return from background; never opens the voice-help dialog by itself.
- Wrong tile: short shake (~0.3 s), then pale red `#FDE2DD` fill, `#E4572E` border/letter, ✕ badge, disabled. Right tile: `#4C9F70` fill, white letter, ✓ badge, scale ~1.06; all other tiles fade (~0.3 alpha) and lock; word with highlighted letter appears under the picture (slot reserved before, empty).
- No auto-advance. ▶ always works (skip); before solve it is grey `#CFC6B6`, after solve green, larger, with a soft glow ring. No ◀ in quiz; swipe right does nothing in quiz.
- Mode chips: «Абетка · Випадково · Знайди» (`R.string.mode_quiz` = `Знайди`).
- Letter sets for questions and for distractors are separate parameters (future: parent-chosen subset). Today both are all letters of the language.
- Must fit without clipping on Redmi Note 9 (1080×2340 @440dpi) and 14T Pro (1220×2712 @460dpi), including system font scale 1.3.
- Existing «Абетка»/«Випадково» behaviour unchanged; all existing tests stay green.
- Work on branch `feat/quiz-mode`; one commit per task; finish with a PR (CI attaches the APK).

## Review Focus

1. **Double/fast taps on tiles** (during shake, after solve, on an already-wrong tile) must not change state twice → Task 1 tests `pick_alreadyWrong_isIgnored`, `pick_afterSolved_isIgnored`.
2. **Speaker flips READY→MISSING_VOICE→READY** (failed utterance, then recheck on return) must not re-trigger auto-speak → Task 2 tests `failedAttempt_countsAsSpoken`, `background_clearsPending`.
3. **Leaving and re-entering «Знайди»** must continue the round (no repeated letters) and not open on the letter whose card was just shown → Task 3 tests `quiz_reenter_continuesRound`, `quiz_firstQuestion_isNotCurrentCard`.
4. **Pool smaller than 4 letters** (future subsets) must still produce a valid question → Task 1 test `newQuestion_smallPool_usesAllAvailable`.
5. **Large font scale** must not clip tile letters or push ▶ off screen → Task 4 emulator step with `font_scale 1.3`.

**Interfaces:**
- Produces:
  - `enum class OptionState { OPEN, WRONG, RIGHT, LOCKED }`
  - `data class QuizQuestion(val answer: Int, val options: List<Int>, val wrong: Set<Int> = emptySet(), val solved: Boolean = false)` with `fun pick(option: Int): QuizQuestion` and `fun stateOf(option: Int): OptionState`. Values are letter indices into `Language.letters`.
  - `fun newQuestion(answer: Int, pool: List<Int>, random: Random, count: Int = 4): QuizQuestion` — `options` = the answer plus up to `count - 1` distinct distractors drawn from `pool` minus the answer (fewer if the pool is smaller), shuffled.

`stateOf`: RIGHT if solved and option == answer; WRONG if in `wrong` (stays WRONG after solve; the UI fades it); LOCKED if solved otherwise; else OPEN. `pick` returns `this` when solved, option already wrong, or option not in options.

class QuizQuestionTest {
    private val all = (0 until 33).toList()

    @Test fun newQuestion_hasFourDistinctOptionsIncludingAnswer() = repeat(200) { seed ->
        val q = newQuestion(answer = 5, pool = all, random = Random(seed))
        assertEquals(4, q.options.size); assertEquals(4, q.options.toSet().size)
        assertTrue(5 in q.options); assertTrue(q.options.all { it in all })
    }
    @Test fun newQuestion_answerLandsInEveryPosition() {
        val positions = (0 until 200).map { newQuestion(5, all, Random(it)).options.indexOf(5) }.toSet()
        assertEquals(setOf(0, 1, 2, 3), positions)
    }
    @Test fun newQuestion_smallPool_usesAllAvailable() {
        val q = newQuestion(answer = 1, pool = listOf(0, 1, 2), random = Random(0))
        assertEquals(setOf(0, 1, 2), q.options.toSet())
    }
    @Test fun pick_wrong_marksWrongAndKeepsGoing() {
        val q = QuizQuestion(answer = 0, options = listOf(0, 1, 2, 3)).pick(2)
        assertEquals(OptionState.WRONG, q.stateOf(2)); assertFalse(q.solved)
        assertEquals(OptionState.OPEN, q.stateOf(0))
    }
    @Test fun pick_alreadyWrong_isIgnored() {
        val q = QuizQuestion(0, listOf(0, 1, 2, 3)).pick(2)
        assertSame(q, q.pick(2))
    }
    @Test fun threeWrongThenRight_solves() {
        val q = QuizQuestion(0, listOf(0, 1, 2, 3)).pick(1).pick(2).pick(3).pick(0)
        assertTrue(q.solved); assertEquals(OptionState.RIGHT, q.stateOf(0))
        assertEquals(OptionState.WRONG, q.stateOf(3))
    }
    @Test fun pick_afterSolved_isIgnored() {
        val q = QuizQuestion(0, listOf(0, 1, 2, 3)).pick(0)
        assertSame(q, q.pick(1)); assertEquals(OptionState.LOCKED, q.stateOf(1))
    }
}

### Task 2: Question order and auto-speak gate

**Files:**
- Create: `app/src/main/java/app/learnalphabet/quiz/QuizDeck.kt`, `app/src/main/java/app/learnalphabet/quiz/AutoSpeakGate.kt`
- Test: `app/src/test/java/app/learnalphabet/quiz/QuizDeckTest.kt`, `app/src/test/java/app/learnalphabet/quiz/AutoSpeakGateTest.kt`

**Interfaces:**
- Consumes: `SpeakerState` from `app.learnalphabet.speech`.
- Produces:
  - `class QuizDeck(private val pool: List<Int>, private val random: Random)` with `fun next(avoid: Int? = null): Int`. Rounds: each pool item once per round; a new round never starts with the item just returned; `avoid` is skipped when any other item is left in the current round (it stays in the round for later). Pool of size 1 always returns that item.
  - `class AutoSpeakGate` with `fun onNewQuestion()`, `fun onBackground()`, `fun consume(state: SpeakerState): Boolean` — returns true exactly once per armed question, only when `state == READY`, and disarms on that call (the attempt counts even if speech later fails). Non-READY states leave it armed. `onBackground()` disarms.

class QuizDeckTest {
    private val all = (0 until 33).toList()
    @Test fun round_coversEveryLetterOnce() = repeat(50) { seed ->
        val d = QuizDeck(all, Random(seed)); assertEquals(all.toSet(), List(33) { d.next() }.toSet())
    }
    @Test fun newRound_doesNotRepeatLastLetter() = repeat(200) { seed ->
        val d = QuizDeck(all, Random(seed)); val seq = List(66) { d.next() }
        assertNotEquals(seq[32], seq[33])
    }
    @Test fun avoid_isSkippedWhileOthersRemain() = repeat(200) { seed ->
        val d = QuizDeck(all, Random(seed))
        val first = d.next(avoid = 7)
        assertNotEquals(7, first)
        assertEquals(all.toSet(), (listOf(first) + List(32) { d.next() }).toSet()) // 7 not lost from the round
    }
    @Test fun singleItemPool_alwaysReturnsIt() {
        val d = QuizDeck(listOf(4), Random(0)); assertEquals(4, d.next(avoid = 4)); assertEquals(4, d.next())
    }
}
